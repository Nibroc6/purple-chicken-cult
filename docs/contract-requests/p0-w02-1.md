# Contract request p0-w02-1: stored mentions and friend-request state for views

**Status:** applied by the contract steward (additive) at the P0-W02 merge; the local adapters in `gate/views` are gone (it reads `d.Mentions` / `d.Requests`, nil = none).
coreref: `(*MemPosts).SetMentions` / `MentionTargets`, `MemRequests`; coretest `NewMem` wires both (`Mem.Requests`). `gate/wire` unchanged: W05 / W03 assign the fields when they implement the methods.

**From:** P0-W02 · **Kind:** additive (two new interfaces, two new optional `Deps` fields)

## Why

`gate/views` must fill `PostView.Mentions` (plan §4.7 views: "Mentions: `Ref` only if
`CanSeeUser(target)`") and `PersonView.Request` ("outgoing" | "incoming"). The data lives in
tables views may not read: `mentions` (writer W05, direct reader `gate/postindex` only) and
`friend_requests` (writer W03, no direct readers). No `core` interface exposes either.

Meanwhile `gate/views` type-asserts `d.Posts` against a local unexported interface with
exactly the `MentionIndex` method set, and `d.Edges` / `d.Mutes` (the friends service)
against one with the `RequestStates` method set. When no implementer is present, views
renders no mentions (the client then shows plain text) and no request state: both fail
closed. After this lands, views switches to `d.Mentions` / `d.Requests` and the adapters go
away.

## Diff

`internal/gate/internal/core/interfaces.go` (append after `PostIndex`):

```go
// MentionIndex resolves a post's stored mentions (impl: gate/postindex). The map is
// ord (index of the @handle occurrence in the body) → target; it holds only the
// mentions resolved at write time within the author's horizon (mentions table).
// Steward: contract request p0-w02-1.
type MentionIndex interface {
	MentionTargets(ctx context.Context, p PostID) map[int]UserID
}
```

`internal/gate/internal/core/interfaces.go` (append after `Mutes`):

```go
// RequestStates exposes the friend-request state between v and u as v sees it
// (impl: gate/friends): "outgoing" (v asked u; a declined request still reads
// "outgoing"), "incoming" (u asked v, pending) or "".
// Steward: contract request p0-w02-1.
type RequestStates interface {
	RequestState(ctx context.Context, v, u UserID) string
}
```

`internal/gate/internal/core/deps.go` (in `Deps`, with the other steward additions):

```go
	// Steward additions (contract request p0-w02-1). Optional: nil until the
	// implementing WP lands; gate/views treats nil as "none".
	Mentions MentionIndex
	Requests RequestStates
```
