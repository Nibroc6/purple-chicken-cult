# Contract request p0-w12-1: remove one post and suspend an account on a moderator's decision

**Status:** applied by the contract steward (additive). `gate/posts/admin.go` (`RemovePost`) and
`gate/users/accounts.go` (`Suspend`) carry working steward bodies; their owners may replace
them. coreref: `MemPostAdmin.RemovePost`, `MemUsers.Suspend`.

**From:** P0-W12 · **Kind:** additive (two new interfaces, two new `Deps` fields, wiring)
**Implementers:** P0-W05 (`gate/posts`), P0-W11 (`gate/users`)

## Why

Moderation (plan §4.7 moderation, §10.4) resolves a report with `remove_post` (one
moderator) or `suspend_user` (two moderators, each with a fresh step-up). Both change rows
the moderation module does not own (plan §3.4): `posts` belongs to W05 and `users.status`
to W11. `core.PostAdmin` only deletes every post of an author (account deletion), and no
interface changes an account's status. Adding methods to existing interfaces would not be
additive, so this asks for two new single-method interfaces.

## Diff

`internal/gate/internal/core/interfaces.go` (after `PostAdmin`):

```go
// PostRemover removes one post on a moderator's decision (impl: gate/posts).
type PostRemover interface {
	// RemovePost tombstones the live post id in tx exactly like posts.Delete
	// (Tombstone record signed with by as the actor; body, salt and mentions
	// hard-deleted) and returns its author; ok is false when the post is not
	// live. The caller runs PostIndex.Delete and publishes PostDeleted after commit.
	RemovePost(ctx context.Context, tx store.Q, id PostID, by UserID) (author UserID, ok bool, err error)
}
```

`internal/gate/internal/core/interfaces.go` (after `Accounts`):

```go
// Suspensions suspends accounts on a confirmed two-person moderator action (impl: gate/users).
type Suspensions interface {
	// Suspend turns the active account id suspended (users.status 0 → 2) in tx;
	// gate.ErrNotFound unless it is active. The caller publishes UserChanged after commit.
	Suspend(ctx context.Context, tx store.Q, id UserID) error
}
```

`internal/gate/internal/core/deps.go` (in `Deps`): `PostRemover PostRemover`, `Suspensions Suspensions`.

`internal/gate/wire/wire.go`: `d.PostRemover = a.Posts`, `d.Suspensions = a.Users`.

`internal/gate/internal/coretest/coretest.go`: the memory deps use the shared
`MemPostAdmin` and `MemUsers`.

Steward bodies: `(*posts.Service).RemovePost` reads the live post's author and calls the
existing `tombstone` with the moderator's `ext_id`; `(*users.Service).Suspend` is
`UPDATE users SET status = 2 WHERE id = $1 AND status = 0`.
