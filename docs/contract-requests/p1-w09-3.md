# Contract request p1-w09-3: advanced themes (theme CSS and theme images)

**Status:** applied with the advanced-theme change (requested by the project owner after P1-W09).

**From:** P1-W09 follow-up · **Kind:** additive (one core interface and `Deps` field, one
migration, two optional request fields and two response fields on `/me/theme`) ·
**Implementer:** contract steward

## Why

The project owner asked for an advanced theme mode: custom CSS and templates, including
things like replacing buttons with custom images. §15.2 rules out user CSS in the app,
because raw CSS can hide or spoof integrity elements, overlay a fake passkey prompt, or
leak data through selectors and `url()`. ARCHITECTURE §15.3 (new) defines **theme CSS**
instead. It's a closed CSS-like dialect over named parts, with allowlisted properties,
bounded values, and the theme's own uploads as the only image source. Integrity
elements, the passkey and co-sign dialogs, and locked routes are out of its reach.
Structural templates stay §16.2's declarative layouts (Phase 2).

## Diff

- `internal/gate/internal/core/p1.go`: `ThemeMedia` (`Release`, `Own`), implemented by
  `gate/media` (`theme.go`). `core.Deps.ThemeMedia` is wired in `gate/wire`; it's optional,
  and `gate/themes` treats nil as "media is off".
- `internal/store/migrations/3120_theme_sheets.sql`: `user_themes.css`, plus
  `theme_images(user_id, name, media_id)`.
- `api/openapi/theme.yaml`:
  - `ThemeIn` gains `css` and `images[{name, ref}]`.
  - `ThemeView` gains `css` (normalized) and `images[{name, ref, w, h}]`.
  - New 422 code `theme_css`. `theme_contrast` can also name a field `css.<line>`.
  - 409 `feature_disabled` when the CSS uses `image()` while media is off.
- `gate/themes`:
  - `sheet.go` holds the parser and validator. It's the authority, and it shares
    `web/src/features/themes/sheet.vectors.json` with the client mirror `sheet.ts`.
  - `Set` attaches fresh uploads with `Media.Attach` and keeps the current images.
  - It releases images the new theme no longer uses; `Clear` releases all of them.
- `web`:
  - `features/themes/sheet.ts` is the parser mirror and the stylesheet builder (a
    constructed stylesheet through the CSSOM, which works under `style-src 'self'`).
  - `ThemeApplier` applies the sheet outside locked routes.
  - The theme page has an "Advanced" section with an editor, live checks, image uploads
    and a preview.
  - `EngageBar` buttons carry `data-part`.
  - `.integrity` resets the inherited typography that theme CSS can set.
