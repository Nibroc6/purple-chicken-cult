# Contract request p0-w11-2: author-wide post deletion and enrollment cancel

**From:** P0-W11 · **Kind:** additive (two new interfaces, two new `Deps` fields, wiring)
**Implementers:** P0-W05 (`gate/posts`), P0-W01 (`gate/auth`)

## Why

* The `account.delete` job must tombstone every post of the deleted account
  (plan §4.7 account, §10.2). `posts` is owned by W05 and `core.PostIndex` only
  mutates the in-memory index.
* A manual-recovery cancel from the account's live session must void an
  enrollment token that was already issued (security #14). `enrollment_tokens`
  is owned by W01 and `core.Passkeys` has no cancel.

Meanwhile W11 uses local adapters, clearly marked in the code:
`account.(*Service).tombstonePosts` (signs a `Tombstone` per live post through
`core.Signer`, then `UPDATE posts SET body = NULL, body_salt = NULL, deleted_at`;
after commit `PostIndex.Delete` + Bus `PostDeleted`) and `account.cancelEnrollment`
(`UPDATE enrollment_tokens SET cancelled_at … WHERE used_at IS NULL`). After this
lands both become single calls and the SQL moves to its owners.

Related note for W12: on a second-moderator recovery approval W11 inserts the
`mod_actions` row (`action = 'recovery_approve'`, both moderators, `second_auth`)
as plan §4.7 account requires; no interface change is needed for that.

## Diff

`internal/gate/internal/core/interfaces.go` (after `PostIndex`):

```go
// PostAdmin deletes posts on behalf of the system (impl: gate/posts).
type PostAdmin interface {
	// DeleteAllBy tombstones every live post of author in tx exactly like
	// posts.Delete (Tombstone record; body and salt NULL) and returns their IDs;
	// the caller runs PostIndex.Delete and publishes PostDeleted after commit.
	DeleteAllBy(ctx context.Context, tx store.Q, author UserID) ([]PostID, error)
}
```

`internal/gate/internal/core/interfaces.go` (after `Passkeys`):

```go
// Enrollments cancels issued enrollment tokens (impl: gate/auth).
type Enrollments interface {
	// CancelEnrollment voids the unused token whose sha256 is tokenHash.
	CancelEnrollment(ctx context.Context, tx store.Q, tokenHash []byte) error
}
```
