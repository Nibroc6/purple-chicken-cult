# Contract request p0-w01-2: retire the scaffold's "login is a stub" router test

**From:** P0-W01 · **Kind:** test-only (frozen `internal/api/router/router_test.go`)
**Implementer:** contract steward

## Why

`internal/api/router/router_test.go` has `TestStubsAnswerNotImplemented`, which
asserts that `POST /api/auth/login/begin` answers `501 not_implemented`. It was a
scaffold placeholder for the W01 stub. P0-W01 implements the login ceremony, so
the route now answers `200 {"options": …, "csrf": …}` with a new guest session
cookie, and the test fails by design (it is the only red test of
`scripts/check-wp.sh p0-w01`). Plan §0.8: no finished code returns
`ErrNotImplemented`.

The behaviour itself is covered by `internal/api/authapi/routes_test.go`
(`TestLoginRotatesTheSessionAndCannotBeReplayed`) and
`internal/gate/auth/auth_test.go`.

## Diff

`internal/api/router/router_test.go`: replace

```go
func TestStubsAnswerNotImplemented(t *testing.T) {
	h := apitest.App(t)
	rec := h.Do("POST", "/api/auth/login/begin", map[string]any{})
	if rec.Code != http.StatusNotImplemented {
		t.Fatalf("login begin: %d %s", rec.Code, rec.Body)
	}
}
```

with

```go
func TestLoginBeginStartsAGuestCeremony(t *testing.T) {
	h := apitest.App(t)
	rec := h.Do("POST", "/api/auth/login/begin", map[string]any{})
	if rec.Code != http.StatusOK || !strings.Contains(rec.Body.String(), `"options"`) ||
		!strings.Contains(rec.Header().Get("Set-Cookie"), "SameSite=Strict") {
		t.Fatalf("login begin: %d %s", rec.Code, rec.Body)
	}
}
```

(`strings` is already imported by the file.)
