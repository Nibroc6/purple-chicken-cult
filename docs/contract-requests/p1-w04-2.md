## Provided by P1-W04

* **`core.Media`** (`gate/media`):
  * `Attach(ctx, tx, owner, refs)` — owner's ready, live, **unattached** uploads, ≤ 4, all or
    none, in the post's transaction (`media.attached_at`); anything else is `ErrNotFound`.
    The caller writes `post_media` in the same transaction. Unattached uploads are deleted
    after 24 h.
  * `Views(ctx, s, ids)` — ready, live items in order with refs for `s.Viewer()`; adds no
    visibility of its own.
  * `Ingest(ctx, img, sourcePost, sourceURL)` — preview images: same scan; a match is held
    (evidence, `csam_holds.source_url`, priority-0 item with `SubjectPost`, the post's author
    held) and answers Problem `media_rejected`; so does a scanner failure. Disabled media is
    `feature_disabled`: skip the image.
* **`core.CSAMHolds`** (p1-w04-1): `Hold` (metadata only), `Report` (once; extends retention
  to a year after the report), `ReleaseAccount`.
* HTTP: `POST /api/media` (multipart `file`, `alt`), `GET /api/media/{ref}/url?variant=`;
  dev/test `GET /m/{key}`; prod `deploy/cloudflare/media-worker.js`.
* `media.process` job: post/account deletion fan-out (Bus `PostDeleted`, `AccountDeleted`),
  unattached sweep, blob delete + CDN purge, evidence expiry (reported holds only).
* Web: `features/media` (`MediaPicker`, `useUpload`, `MediaImage`) and the `/media/check`
  page (a standalone upload check until posts carry media).

## Follow-ups

* **P1-W12 (posts):** `Media.Attach` in the post transaction, then `post_media` rows; Post
  record lists the media ids; `Views` for `PostView.media` and `PreviewView.image` (from
  `link_previews.image_media_id`); render with `MediaImage` (feed: `display`, tree rows:
  `thumb`); composer uses `MediaPicker` (max 4). `GET /api/media/{ref}/url` already checks
  the post's visibility through `post_media`, so "media of an invisible post ⇒ 404" holds
  once the rows exist. Deleting a post publishes `PostDeleted` (media follows).
* **P1-W11 (previews):** `Media.Ingest` per `og:image`; on any error leave
  `image_media_id` NULL. "The linking post held" is implemented as: the image is never
  stored or served, the item names the post and its author's uploads are held; removing
  the post itself stays a moderator decision (`PostRemover`).
* **P1-W06 (moderation):** write `ModQueueItem.Media` to `mod_queue.subject_media`; the CSAM
  item view calls `d.CSAM.Hold` (never a PostView or media URL); the two-person
  `csam-report` confirmation calls `d.CSAM.Report` in its transaction; a reviewed false
  positive may call `ReleaseAccount`. Runbook: `deploy/runbooks/csam.md`.
* **INT-1:**

    `display` → unfriend → URL 404); decide whether `/media/check` stays.
  * Padding: `GET /media/{ref}/url` has `{ref}` and is padded by `apix/pad` (P1-W07).
  * Prod deploy: R2 private bucket + evidence bucket with a 1-year lock, Worker secret
