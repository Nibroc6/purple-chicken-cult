# Contract request p1-w01-1: co-sign drafters and offline assertion checks

**Status:** applied (additive) in the P1-W01 branch, in its own `steward:` commit.
coreref: `MemCosign.RegisterDrafter`, `DraftMatches`; sigs: `VerifyAssertion`, `AssertionChallenge`.

**From:** P1-W01 · **Kind:** additive (one new func type, one new interface, two new sigs functions)

## Why

1. **The challenge must cover the draft at Begin.** ARCHITECTURE §3 Phase 1 and plan
   P1-W01 sign `H("pcc-v1:" ‖ kind ‖ JCS(record))`, and the WebAuthn challenge is fixed
   when the client calls `navigator.credentials.get`, i.e. at `POST /api/cosign`. But
   `Cosign.BeginIntent(ctx, v, purpose, target)` has no record: only the module that
   owns a purpose (friends, invites, auth, account, moderation) knows how to build its
   record body, and A8 forbids cosign from importing them. So the owner registers a
   drafter for its purpose, and Require checks the body the owner is about to write
   against the stored draft.
2. **Exports must verify assertions offline.** `records.VerifyExport` checks the passkey
   assertions every co-signed record carries (security #5), and the WebAuthn signature
   check needs a COSE parser. A leaf helper in `platform/sigs` keeps the go-webauthn
   import out of the domain packages.

## Diff

`internal/gate/internal/core/p1.go` (after `Cosign`):

```go
type Drafter func(ctx context.Context, v Viewer, target gate.Ref, issuedAt time.Time) (RecordKind, any, error)

type CosignDrafters interface {
	RegisterDrafter(purpose string, f Drafter)
}
```

Every `core.Cosign` also implements `CosignDrafters`, so no `Deps` field or wiring change
is needed: an owner calls `d.Cosign.(core.CosignDrafters).RegisterDrafter(...)` in its
`Init`.

`internal/gate/internal/coreref/p1.go`: `MemCosign.RegisterDrafter` (with a drafter, the
reference drafts at Begin and challenges over the draft, like gate/cosign) and
`DraftMatches(draft, kind, body)`: every field of body equals the draft's, and the
draft may add only `nonce`, `issued_at`, `created_at` and `at`.

`internal/platform/sigs/webauthn.go`: `VerifyAssertion(AssertionCheck, authData,
clientDataJSON, sig)` (webauthn.get, exact challenge, optional exact origin, no
crossOrigin/topOrigin, UP and UV, signature under the COSE key) and
`AssertionChallenge(clientDataJSON)`.

## How a caller uses it (P1-W02, W03, W06, W07, W10)

```go
// Init
d.Cosign.(core.CosignDrafters).RegisterDrafter("friend_accept", func(ctx context.Context, v core.Viewer,
	target gate.Ref, at time.Time) (core.RecordKind, any, error) {
	peer, ok := d.Refs.OpenUser(v.ID, target)
	if !ok { return 0, nil, gate.ErrNotFound }
	return core.RecFriendship, friendship{A: a, B: b, Level: "friend", CreatedAt: sigs.T(at)}, nil
})

// The write (client sends {intent, assertion} from requestCosign() in web/src/features/cosign)
err := d.DB.Tx(ctx, func(tx pgx.Tx) error {
	a, draft, err := d.Cosign.Require(ctx, tx, v, "friend_accept", core.RecFriendship,
		map[string]any{"a": a, "b": b, "level": "friend"}, in.Intent, in.Assertion)
	if err != nil { return err }
	_, err = d.Signer.Sign(ctx, tx, core.RecFriendship, v.ID, json.RawMessage(draft), parties, a)
	return err
})
```
