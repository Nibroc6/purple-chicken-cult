# Contract request p0-w11-1: display names and record export through core

**Status:** applied by the contract steward (additive) at the P0-W11 merge; the local adapters in `gate/account` are gone.
coreref: `DisplayNameFunc`, `(*ServerSigner).ExportRecords`; coretest `NewMem` wires both.

**From:** P0-W11 · **Kind:** additive (two new interfaces, two new `Deps` fields, wiring)

## Why

`gate/account` (W11) must validate display names with the rule that lives in
`gate/users/reserved.go`, and must put the caller's signed records and the
published keys into the export zip, which `gate/records` owns. Archtest A8 forbids
`account` from importing `users` or `records`, and neither `core.Users` nor
`core.Signer` has such a method.

Meanwhile `gate/account` type-asserts `d.Users` and `d.Signer` against local
unexported interfaces with exactly these method sets (`account.displayNames`,
`account.recordExporter`); `*users.Service` and `*records.Service` already
implement them. After this lands, account switches to `d.DisplayNames` /
`d.RecordExporter` and the adapters go away.

## Diff

`internal/gate/internal/core/interfaces.go` (append after `Users`):

```go
// DisplayNames validates display names (impl: gate/users): NFC, ≤ 50 code points,
// graphic code points and plain spaces only, none of the integrity glyphs.
type DisplayNames interface {
	CleanDisplayName(name string) (clean string, ok bool)
}
```

`internal/gate/internal/core/interfaces.go` (append after `Signer`):

```go
// RecordExporter produces the signed part of an export (impl: gate/records):
// records.jsonl (the exact stored envelopes of every record user is a party to,
// never Report records of others) and keys.json ({"server": [KeyView]}).
type RecordExporter interface {
	ExportRecords(ctx context.Context, q store.Q, user UserID) (recordsJSONL, keysJSON []byte, err error)
}
```

`internal/gate/internal/core/deps.go` (in `Deps`, after `Signer`):

```go
	DisplayNames   DisplayNames
	RecordExporter RecordExporter
```

`internal/gate/wire/wire.go` (with the other assignments):

```go
	d.DisplayNames = a.Users
	d.RecordExporter = a.Records
```

`internal/gate/internal/coretest/coretest.go` `NewMem` (optional, memory tests):

```go
	d.DisplayNames = displayNamesFunc(func(s string) (string, bool) { return s, true })
```
